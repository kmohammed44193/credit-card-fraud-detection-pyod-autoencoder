# Credit Card Fraud Detection with PyOD AutoEncoder

1. Download the Kaggle anonymized credit card dataset and locate `creditcard.csv`.
2. Install Python 3.10+ and run `python -m pip install -r requirements.txt`.
3. Run `python fraud_detection.py --data creditcard.csv`.
4. View `outputs/metrics.json`, `outputs/predictions.csv`, and the three PNG plots.
5. Push `fraud_detection.py`, `requirements.txt`, and `README.md` to a public GitHub repository. Do not upload the dataset unless permitted by its license.
